Free hosting option — GitHub Pages:
1. Create a repository named e.g. ankushpal-portfolio.
2. Upload index.html, style.css, script.js, README.txt and the complete assets folder.
3. In repository Settings → Pages, choose deploy from the main branch/root.
4. Use the generated Pages URL. Hosting terms/availability are subject to GitHub's current plan.

The site loads Google Fonts from a CDN. All other site code and project images are included locally.
